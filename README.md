# Password Generator

Простой генератор сложных паролей любой длины.

## Возможности

* Настройка длины пароля.
* Вывод пароля в консоль

## Стек технологий

* Python 3.14.7+
* Библиотека `random`

## Установка

1. Скачать файл
2. Скачать python

## Использование

Запустить main.py через python
